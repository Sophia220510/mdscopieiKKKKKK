# Elegance Studio

Prompt

Quero que você crie um site completo, moderno e extremamente profissional para um salão de beleza pequeno e humilde localizado no centro de São Paulo.

NÃO quero um site exagerado ou com aparência de grande rede.

Quero um visual premium, elegante, minimalista e acolhedor.

Use como inspiração apenas o estilo visual do início do site da Soho Hair (hero grande, tipografia elegante, bastante espaço em branco, imagem de destaque e animações suaves), mas crie um design totalmente original.

O objetivo é que qualquer pessoa que entre no site pense:

"Nossa, esse salão parece extremamente profissional e confiável."

Uma dica: se você pretende vender esse modelo para vários salões, peça para o Lovable criar tudo com conteúdo em arquivos separados (dados da equipe, serviços, avaliações, contatos etc.). Assim, depois você só troca nome, fotos, WhatsApp e endereço e consegue reutilizar praticamente o mesmo projeto para outros clientes em poucos minutos.
